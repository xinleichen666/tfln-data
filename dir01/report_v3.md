# 方向 1 第 3 轮报告：真实膜厚起伏谱与"膜厚 vs 泵浦啁啾"判据

## 1. 真实起伏谱（Chen 2023 Fig. 1d，arXiv 全文）
- **取数方法**：没有手工描点，而是从 PDF 里的矢量路径直接取出 526 个点，再用坐标轴刻度定标。读图误差小于 0.01 nm。但作者作图前有没有平滑或降采样不知道，测量仪器的单点重复精度论文也没给（只写了用宽带反射谱测量），所以下面的短尺度数字都是上限。数据：`data/chen_fig1d_thickness.csv`。
- **结果**：21 mm 内膜厚 597.2–609.7 nm；5 mm 窗口内 RMS 0.64–1.81 nm（和 Lu 2023 估计的 1.59 nm 同一量级）。功率谱斜率 −1.44（0.2–5 /mm）、−1.90（>5 /mm），都比 1/f（−1）陡。0.2 mm 以下的成分 RMS ≤0.31 nm。
- **判断：接近谱 A。** 短尺度成分很小，而且可能包含测量噪声。第 2 轮的谱 B（1/f 一直到畴尺度）太悲观了。注意这只是一块晶圆、一条线上的数据。

## 2. 用真实曲线算纯度（type-II 设计，L=5 mm，9 个窗口）
| 策略 | 纯度（9 个窗口的范围） |
|---|---|
| 不处理 | 0.54–0.80 |
| 自适应极化，每 0.2 mm 测一次（短尺度当真实） | 0.84–0.96 |
| 同上（短尺度当测量噪声） | 0.99 |
| 每 40 µm 测一次，测量误差 0.1 nm / 0.3 nm（误差是假设值） | 均值 0.993 / 0.975 |
| 理想 | 0.994 |
| 前沿实测（Kuttner，全文） | JSI 93.8–95.2%，g(2) 81.5–88.4% |

## 3. 区分判据（台面经典测量 + 可选的 g(2)）
物理依据：泵浦啁啾带来的相位只依赖 Ωs+Ωi，强度谱不变；膜厚起伏带来的相位依赖 Δk = AΩs+BΩi，会同时改变 |PMF|。

| 测量 | 用到的器件 | 泵浦啁啾为主时预期 | 膜厚为主时预期（Chen 曲线） |
|---|---|---|---|
| A. CW-SFG 扫 PMF 强度（Kuttner 也这么测过） | 两台可调 C 波段激光（TE / TM 各一台）、偏振控制器、Si 探测器或光谱仪 | 和设计一致 | 与设计高斯的重叠 0.13–0.88，峰值降到 19–78%，带宽变宽约 3 倍以上 |
| B. 只看强度的 JSI 纯度 vs g(2) 纯度 | 色散光纤飞行时间谱仪 + SNSPD；光纤 HBT | JSI ≈0.995，g(2) 降到 0.92（0.5τ²）/ 0.78（1τ²） | JSI 和 g(2) 一起降：0.79 / 0.76（窗口 4），0.34 / 0.33（窗口 10）（泵浦带宽固定在理想最优值） |
| C. 扫泵浦啁啾，看 g(2) 纯度 | 775 nm 飞秒光 + 棱镜对或光栅压缩器（或已知 GDD 的玻璃块，GDD 按厂家数据算） | 加 −C 时回到 0.994，曲线对称 | 最大值几乎不变（0.76→0.78，0.33→0.33），补不回 |

A 不需要单光子探测，最便宜，可以单独作为初筛。
**对照前沿**：Kuttner 的 |PMF| 旁瓣压制良好（由 PMF 估计纯度 98%），JSI 95%、g(2) 82–88%。这正是"啁啾型"的特征，和作者自己"泵浦啁啾 + 极化不理想"的解释一致。也就是说，**前沿器件在它的长度下并没有被膜厚卡住**。

## 4. 结论（有条件提升，但卖点变了）
- **有提升的部分**：膜厚起伏和 Chen 晶圆相当时，5 mm 器件不处理只有 0.54–0.80。每 40 µm 测一次再自适应极化可以回到 0.97–0.99，每 0.2 mm 测一次也能到 0.84–0.99。起伏谱接近 A，所以这条路在物理上可行。
- **限制**：现有前沿器件的纯度主要不是被膜厚限制，所以"提升现有纯度"这个说法站不住。真正的卖点应该是：做更长、更亮的器件，或者用均匀性更差的晶圆时，保住纯度。
- **新颖性**：Chen 2023 的自适应极化只用在 SHG 效率上；第 3 节的判据我没检索到有人这样系统地提出过，但检索不充分，需要再查 SET 和"JSI vs g(2)"相关的文献。
- **实验限制**：你手上的商用体 PPLN / PPKTP 没有膜厚问题，台面上只能用判据 B、C 验证"啁啾"那一半。膜厚那一半要等拿到 TFLN 芯片（MPW 或合作者）。

## 5. 建议下一步
1. 写设计/理论短文："TFLN 预报单光子源的纯度-亮度-长度极限，以及自适应极化方案"。用真实膜厚曲线，给出测量间隔和测量误差的要求，再附上第 3 节的判据。
2. 补齐：纯度×亮度随 L（2–20 mm）的曲线；宽度和刻蚀起伏的贡献（刻蚀灵敏度需要修正侧壁角后重算）；再找第二组公开膜厚数据，避免只靠一块晶圆。
3. 台面：用体 PPKTP 加棱镜对做判据 C 的啁啾扫描，验证模型。
