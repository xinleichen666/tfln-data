## 1. 本周不依赖 Tidy3D

本周不把 Flexcompute 放进关键路径。账号和剩余额度要有人明确认领；不认领就当没有。

以后接上的做法：

## 2. 无 Tidy3D 时怎么排

Meep 在普通 Linux 上的安装通常不是卡点。`conda install -c conda-forge pymeep` 这条二进制路径一般能装上；从源码编 MPI 和 Python 绑定才容易因 Guile、HDF5、OpenMPI 版本卡住。

难的是把这个器件算到 20 dB 还可信：

- X-cut 的 \(n_e\)、\(n_o\) 要对着晶体轴写进实验室坐标。波导沿晶体轴时张量可以是对角的；版图在面内转角就有非对角项。
- 1500–1600 nm 不能只用 1550 nm 一个折射率。稳妥做法是每个波长用 Sellmeier 算一次；若用 Meep 的色散极点做一次宽带脉冲，拟合误差要单独检查。
- 侧壁按「相对水平面 70°」理解，也就是离垂直面约 20°。半刻蚀 200 nm 时单侧横向伸出约 \(200\cot 70^\circ \approx 73\) nm。Meep 用直角网格，这段斜壁会变成阶梯；各向异性界面上的亚像素平均要单独做收敛，不能假设和各向同性介质一样稳。若锁定包把 70° 定义成相对垂直面，几何数字要改，求解器排序不用改。
- 半刻蚀留下约 200 nm 平板，平板模和辐射会进入 PER。端口分解必须用带平板的同一截面。
- 42 µm 加端口和 PML、大约 25 nm 的网格，元胞数在一亿量级。普通单机适合做直波导 neff 基准，不适合把「装完 Meep 就出 PBS 光谱」当成下一步。再加密到能看清 73 nm 斜壁时，内存和步数再上一个量级。

Lumerical FDTD/MODE 把侧壁角、铌酸锂各向异性和模式展开做成了现成流程。有人能用已授权的许可证时，它是名义全波的第一选择。COMSOL 的贴体网格对 70° 侧壁是优点，适合截面模和单个波长的三维核对；42 µm、两个偏振、一百纳米带宽、20 dB 动态范围的频域扫描吃内存，不作为宽带主路径。

工时和风险从低到高（Lumerical 与 COMSOL 是否在手都未知）：

| 顺序 | 路径 | 现在可以落下来的东西 | 主要风险 |
| --- | --- | --- | --- |
| 1 | 截面模 + 参考结构的 EME | 方法小节和几何扫 | 被误当成名义光谱 |
| 2 | 已授权的 Lumerical FDTD/MODE | 确认后作为名义全波 | 没人认领许可证 |
| 3 | 已授权的 COMSOL | 截面，或一个波长的三维核对 | 宽带扫描不适合当主路径 |
| 4 | 自装 Meep | 安装，以及直波导 neff 对 Sellmeier 的收敛 | 阶梯侧壁和各向异性使 20 dB 结果先不可引用 |
| 5 | Tidy3D 3D FDTD | 账号确认之后的名义光谱候选 | 本周没有账号 |

默认走第 1 条。同一天问清第 2、3 条。两条都没有，再做第 4 条里的安装和直波导基准。第 5 条不进入本周依赖。

EMpy、Lumerical MODE 或自写耦合模，够写「方法 + 几何扫」，不够当名义光谱。这件是紧凑逆设计，不是缓变锥：反射、散射和半刻蚀平板泄漏都动得到 1% 功率。仓库里的自写 EME 是一阶前向、面向缓变锥的。方向 C 那套的功率守恒误差约 ±3%，作者已经写明大约 15 dB 以上的 PER 不可靠；另一套缓变锥的截面插值损耗约 0.5%。这两条都只说明旧方法的地板，不是本 PBS 的光谱，不要画进新图。

## 3. FDTD 之前可以写的小节

组内已经允许写 EME 几何扫，条件是标明 pending，并且不能当名义光谱。这里把范围收到截面和参考几何上。对 42 µm 逆设计版图做器件级 EME，即使打了水印，也仍然像一张光谱，这周不画。

应写：

- 锁定表：X-cut、膜厚 400 nm、半刻蚀、侧壁角的定义、L≈42 µm、DUV 下限、1500–1600 nm。
- 目标作为目标：「希望 min(PER_TE, PER_TM)>20 dB」。同一句写上全波结果尚未计算。
- 求解器名称、晶体轴、Sellmeier 出处、模式数、网格。用了 EME 就写明前向一阶还是双向，并写上功率误差。
- 1550 nm 的 TE/TM 模场和 neff；neff 或拍长对宽度、间隙、侧壁角，波长至少 1500、1550、1600 nm。
- 后续接口：同一几何交给 Lumerical、收敛后的 Meep，或日后的 Tidy3D。

不该写：

- PER、插损或透射对波长。示意曲线和带 pending 水印的器件光谱也不写。光谱位置留空。
- 「已经大于 20 dB」或「带宽 100 nm」这种结果句。
- 与 FAQUAD（arXiv:2407.04995）或其他实验文章并列的性能行。该文只作为 STA 加流片的方法锚点。
- toy MC 的良率、容差或工艺角 PER。toy MC 继续标成非 FDTD。
- 用矩形截面代替 70° 侧壁，或用单一各向同性折射率代替 X-cut 的 \(n_e\)、\(n_o\)，却不在图注里说明。仓库里已有的 femwell 定向耦合脚本就是垂直侧壁加各向同性近似，不能直接拿来当 V0 截面。
