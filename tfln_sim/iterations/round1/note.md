# 第 1 轮：X 切、Y 传播、空气上包层，扫描膜厚 / 刻蚀深度 / 侧壁角（共 24 组）

**方法**
- 求解器：Tidy3D 本地 ModeSolver，材料色散用 Zelmon Sellmeier。
- 定位反交叉：底宽 w 在 0.6–6 µm 内先粗扫，再用二分法找到 TE 占比 = 0.5 的位置，即 TM0–TE1 反交叉点，记最小间隙为 g。
- 长度估计：用 Landau–Zener 公式，线性锥形覆盖宽度 S = max(10g/α, 0.4 µm)，给出 99% 转换所需长度 L99。
- 有效性要求：杂化模的 neff 必须比剩余平板 TE0 高 0.03 以上，用来排除泄漏解。

**结论**
- 膜厚是主导因素：

  | 膜厚 | g | 对应宽度 | L99 |
  |---|---|---|---|
  | 600 nm | ≈0.003–0.004 | w≈3.5 µm | ≈2 mm |
  | 500 nm | 0.011–0.017 | | |
  | 400 nm（刻蚀 70%） | 0.034 | | 214 µm |
  | 300 nm 全刻蚀 | 0.037 | | 197 µm |

  这一趋势与文献（arXiv:2407.04995）一致。
- 60° 侧壁比 75° 的 g 大 20–40%，原因是斜侧壁本身提供了上下不对称。
- 浅刻蚀（50%）的 300/400 nm 膜，TM0 会低于平板模而泄漏，判为无效。
- 淘汰：600 nm X 切 Y 传播 + 线性绝热方案（mm 级）。
- 保留：薄膜方案，以及下一轮要测试的传播方向。
