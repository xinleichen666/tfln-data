# 方向 B：工艺容差鲁棒 PSR（600 nm X 切、Z 向传播）—— 总结

> 全部为本地模式求解 + 自写 EME/超模传播的仿真结果，未用 FlexCredit，未跑 3D FDTD。工艺角：宽度 ±50 nm、刻蚀 ±20 nm、间隙 ±30 nm、侧壁 55°/65°；波长 1450/1550/1650 nm（机器被并行任务占满，只算了 3 个波长点）。

## 一句话结论
**没有做出“所有工艺角 × 1450–1650 nm 全带 PER>20 dB 且长度有竞争力”的设计。** 主要瓶颈不是 ADC，而是 TM0→TE1 锥形段在欠刻蚀（280 nm）、长波（1650 nm）时卡在约 −15 dB，加长也没用。这个方向目前不值得写文章，也不值得花 3D FDTD 的额度。

## 做了什么
1. **把相位匹配 ADC 换成绝热（渐变）ADC**：窄臂宽度 1.0→1.5 µm 渐变，扫过 TE1(宽)/TE0(窄) 反交叉点。
   - 好消息：所有工艺角下，反交叉点只在 1.175–1.25 µm 之间移动，相位匹配本身对工艺很不敏感。TE0 交叉串扰 ≤ −46 dB。
   - 坏消息：最小劈裂太小（间隙 0.3 µm 时 0.006–0.015，0.2 µm 时 0.009–0.019），绝热转换需要很长：
     - 间隙 0.3 µm：300 µm 时最差残余 −17.5 dB；
     - 间隙 0.2 µm：200/300 µm 时最差残余 −18.8/−21.3 dB。
   - 端口必须用 S 弯渐开间隙（否则端口失配残余地板 −10~−19 dB）。
2. **锥形段工艺角**：除 280 nm 刻蚀外，153 µm 以上残余都 ≤ −21 dB；280 nm 刻蚀 @1650 nm 一直约 −15 dB（TM0 起点靠近平板泄漏截止）。
3. **合成整器件**（锥形 200 µm + 绝热 ADC 300 µm，间隙 0.2 µm）：

| 指标（9 角 × 3 波长最差） | 数值 |
|---|---|
| 直通口 PER | 14.7 dB（280 nm 刻蚀@1650 nm）；排除该角 19.4 dB |
| 交叉口 PER | ≥ 50 dB |
| TM→TE0 转换损耗（不含散射/弯曲） | ≤ 0.15 dB |
| 总长（含 S 弯估计） | 约 550 µm |

## 有用的结论（可以作为后续设计规则）
- TFLN Z 向 PSR 的 PER 地板来自锥形段在欠刻蚀时的泄漏截止，**名义刻蚀深度建议定在 ~320 nm（工艺窗 300–340 nm）**，而不是 300 nm。（340 nm 角尚未算。）
- TE1/TE0 相位匹配点对工艺极不敏感，ADC 的主要问题是耦合太弱，而不是失配。

## 建议
- 停止方向 B 作为独立文章方向；把“刻蚀 320 nm + 等绝热锥形”作为方向 A 或后续器件的设计规则。
- 若要继续：(1) 补算刻蚀 340 nm 角 和 320 nm 名义的锥形；(2) 加入亚波长/SWG 增强耦合或 STIRAP 三波导以缩短 ADC，但后者 Li 2025 已做。
- **3D FDTD：不建议跑**，本轮没有建模也没有询价。
