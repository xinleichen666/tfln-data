# 论文 B 现实条件结果（realistic.py）

参数和来源见 `data/params_sources.md`。core.py 和 paper/ 没有改动。

## 1. 驱动功率（AO，dw = 0.552 GHz 固定）
- IDT 效率 50%、声学 Q = 2000：6.7 µW；10%：33.7 µW。10% 正好是 50% 的 5 倍，和原有表格一致。
- 声学 Q 取下限 1570 时（假设功率 ∝ 1/Q_a）：IDT 10% 需要 43 µW，50% 需要 8.6 µW。MC 中 IDT 10% 的功率 p10/50/90 为 20 / 26 / 38 µW。
- RF 线宽 F/Q_a：Q_a = 1570 时 2.12 MHz（Q_a = 2000 时 1.67 MHz，3600 时 0.93 MHz）。在模型里 Q_a 只影响功率和 RF 带宽，不影响 η_shift。

## 2. 热窗口（计入热膨胀后 df/dT = 5.58 GHz/K，是只算热光时的 2 倍）
- 共模：η ≥ 0.95 要求 ±9.8 mK，η ≥ 0.90 要求 ±15 mK。
- 两环差分：η ≥ 0.95 要求 ±18.6 mK，η ≥ 0.90 要求 ±28 mK。

## 3. 额外损耗（假设 κ_i 加倍）
标称点的 η_shift 是 0.977，基本不变，但片上插损从 2.49 dB 增加到 4.78 dB，绝对效率从 55% 降到 32%。

## 4. Monte Carlo（N = 1000）
包含：间隙误差 5 nm（作用于 μ 和 g），RF 重调 ±35 MHz，锁定残差 5 mK，Q_i 离散，Q_a 1570–3600。

| 量 | p10 | 中位数 | p90 |
|---|---|---|---|
| η_shift | 0.857 | 0.954 | 0.981 |
| 片上插损 (dB) | 3.81 | 4.92 | 5.92 |
| 片上绝对效率 | 23% | 30% | 40% |
| 光纤到光纤绝对效率（每端 1.5 dB） | 11.7% | 14.9% | 19.9% |

η ≥ 0.95 的比例为 54%，η ≥ 0.90 的比例为 81%。间隙误差造成的 2μ−Ω 标准差达到 114 MHz，其中 76% 的样本超出了 ±35 MHz 的 RF 重调范围。

## 5. 敏感性（各项假设单独扫描，N = 300，取中位数）
- 额外损耗 +0 / +100 / +200 / +400%：η 为 0.96 / 0.96 / 0.89 / 0.54，插损为 2.5 / 4.8 / 6.6 / 7.9 dB。
- 锁定残差 1 / 5 / 10 / 20 mK：η 为 0.963 / 0.958 / 0.929 / 0.80。p10 从 0.91 降到 0.28。
- 间隙 σ 1 / 5 / 10 / 20 nm：η 为 0.968 / 0.958 / 0.916 / 0.785。
- RF 重调 0 / 35 / 300 MHz：p10 为 0.82 / 0.86 / 0.92。
- 光纤耦合 0.5 / 1.5 / 3 dB 每端：光纤到光纤效率中位数为 24% / 15% / 7.5%。

## 6. 对论文主张的影响
- 和 Shao 2020（片上 3.5%，30 dBm）相比：现实条件下片上绝对效率中位数约 30%（p10 为 23%），光纤到光纤约 15%，功率是几十 µW，仍然高出约一个数量级，而且功率低 4 个数量级以上。所以"AO 频移器记录"的说法在现实条件下仍然成立（仍是仿真结论）。
- 但 "98%" 不应该作为标题数字。现实条件下 η_shift 中位数是 95%，p10 是 86%；绝对效率是 30% 而不是 55%。
- 最关键的两项工艺要求：共模锁定精度达到约 10 mK，以及 2μ 和 Ω 的匹配（耦合间隙精度约 5 nm，或者需要宽带 IDT 来重调 RF）。这两项都应该写进局限部分。
