# 论文 B 容差分析（热漂移 / 两环失配 / 耦合偏差）

脚本 `tol_scan.py`（core.py 未改动，复制并向量化了 run()，增加 δr 和 2μ−Ω），AO 模式，驱动 dw = 0.552 GHz（make_all 最优点）。零偏移点复现 η_shift = 0.9835，IL = 2.49 dB。

| 扰动 | η≥0.95 区间 (MHz) | η≥0.90 区间 (MHz) | 对应温度（取窄侧半宽） |
|---|---|---|---|
| 共模失谐 Δ（激光相对两环） | −72 ~ +55 | −97 ~ +85 | ±20 mK (0.95) / ±31 mK (0.90) |
| 两环失配 δr（环2相对环1） | −104 ~ +145 | −159 ~ +195 | 差分 ±37 mK / ±57 mK |
| 耦合偏差 2μ−Ω | −96 ~ +53 | −142 ~ +94 | （制造量，不换算温度） |

插损：在 η≥0.95 范围内 IL 保持 2.5–2.66 dB，基本不变。

温度换算：df/dT ≈ −(f/n_g)·dn/dT，f = 193.4 THz，n_g = 2.3，dn_e/dT ≈ 3.3×10⁻⁵ /K（同成分 LN，1550 nm，室温；Moretti et al., J. Appl. Phys. 98, 036101 (2005)），所以 |df/dT| ≈ 2.8 GHz/K。这里只算了热光效应，热膨胀（约 1.5×10⁻⁵ /K）会让漂移再大约 30–40%，温度容差也要相应收紧。

要点：
- 共模稳定度要做到约 ±20 mK 才能维持 η≥0.95，必须用热电极或激光锁到谐振上主动锁定，被动温控做不到。
- 2D 图 (c) 显示两环失配沿 Δ ≈ δr/2 方向可以通过重新调激光频率补偿。用环 2 上的加热电极也能把失配 δr 直接调回 0，所以失配本身主要是标定问题，不是根本限制。
- 2μ−Ω 要控制在约 ±50 MHz 以内（约为 Ω 的 1.6%）。它由耦合间隙决定，属于制造容差，可以通过调 RF 频率 Ω 去匹配实际的 2μ 来补偿；但要考虑声学谐振带宽，并且 IDT 要重新设计。
