## 2. 可调 MZI 耦合器 + 隔热设计意图

| 项 | 交付要求 |
|---|---|
| **耦合器形式** | 环–环 **MZI 型可调耦合器**。仿真自标：`µ = µ_gap · sin(Δφ/2)`，Δφ∈[0,π]。**教科书假设，非 Zhang 2019。** |
| **加热臂** | 至少一臂热调。意图对齐 **Maeder 几何假设**：Pπ=**44.4 mW**（~1 mm Au 臂量级）。**标「Maeder 几何假设，非本版图环–环实测标定」。** 须独立电引出做 Pπ 标定。 |
| **相位量程** | 意图：能把 \|2µ−Ω\| 收到 **±1 MHz** 级；仿真加热 ON hit=100%，P_h 中位 ~22 mW。 |

### 2.1 隔热设计意图（冲 v2 3/2 mK · **非已测**）

目标仿真假设：**@Pπ → ΔT_cm=3 mK、ΔT_diff=2 mK**。下列为**设计意图**，验收以开环步1实测为准：

1. **间距**：MZI 加热臂与两环波导 **尽量拉开**（工艺允许下最大化）。  
2. **禁止金属热桥**：加热金属条 / 走线 **不得**大面积搭在两环上或把两环热短接。  
3. **热路径分离**：环锁定加热 vs 耦合器加热 **分区走线、分区焊盘**；避免共用大热沉。  
4. **隔热槽**：工艺允许则在耦合器–环之间加 **trench / 空气槽**（深度/宽度跟 foundry；不编文献宽度）。  
5. 意图失败（步1 测不到 3/2）→ 走 §6 回退，**不**用「差不多」插值。

| 加热器 | 作用 | 驱动 |

| （可选）暗参考环加热 | 一般 **不加电**；仅作光学频率参照 | 若有加热亦须独立且步1 冻结 |

Pad 表写入 GDS 注释 / 随片 README。

### 4.1 开环步1 程序（必须按此写进测试 SOP）

**目的**：在环锁定环路**不介入**的条件下，单独量化 MZI 加热 → 双环的共模/差分热串扰，并在**实测 Pπ**处与 3/2 mK 比较。

1. **准备光谱**：主双环透射（或反射）可分辨劈裂/两峰；**暗参考环**同一光路或可切换，作频率标尺。  
2. **冻结环加热**：环1、环2 加热电流/功率 **固定为常数或断开**（开环）；**关闭**任何锁定伺服 / 反馈。确认冻结后主双环谱在无 MZI 扫描时稳定（可记基线）。  
3. **只扫 MZI 加热**：单调扫耦合器加热功率（或电流→换算功率）；每点记录：  
   - 双环劈裂 / 反交叉 → 2µ(P)；  
   - 两峰（或两环）频率 f₁(P)、f₂(P)；  
   - 暗参考环频率 f_ref(P)（同芯片、同温台）。  
4. **提取共模 / 差分**（设计意图定义，测法写清即可）：  
   - 共模代理：例如 `(f₁+f₂)/2 − f_ref` 相对 P=0 的漂移 → 换算 ΔT_cm（用本目录已采用的 df/dT≈5.58 GHz/K **仿真换算**，或同芯片标定的 df/dT；**换算系数来源须标注**）；  
   - 差分代理：例如 `f₁−f₂` 相对 P=0 的漂移 → ΔT_diff。  
5. **定实测 Pπ**：由 2µ(P) 或 MZI 透过/劈裂对功率的半周期行为，得到本片 **Pπ_meas**（可与 Maeder 44.4 mW 对照，**不**把 44.4 填进实测栏冒充）。  
6. **Pass/Fail @ Pπ_meas**（硬阈值，**不许插值**）：  
   - **PASS**：在 P≈Pπ_meas 处，估计的 ΔT_cm ≲ **3 mK** 且 ΔT_diff ≲ **2 mK**（与 v2 假设相容）；且加热量程内 \|2µ−Ω\| 能进 ±1 MHz 窗。  
   - **FAIL**：任一条不满足。包括：**好于 v1 串扰假设但未达到 3/2 mK** → 仍 **FAIL**。  
   - **禁止**：用「测得 5 mK → 在 v1/v2 之间按比例报成品率」。要么 v2 闸门过，要么整条回退 v1 数字。  
7. **记录**：Pπ_meas、ΔT_cm(Pπ)、ΔT_diff(Pπ)、是否冻结确认、光谱原始档；实测栏只填本次测量，不抄文献。

**能力要求（版图+仪器）**：必须能在环加热冻结时采主双环 + 暗参考环光谱；否则 **HOLD GDS** / 不得宣称步1可做。
