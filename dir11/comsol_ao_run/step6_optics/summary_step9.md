# Step 9：悬空段与普通波导之间的光学过渡（二维模式匹配）

> 本稿仅限课题组内部：仿真与方案工作稿，实测待做，无伪造数据，Fiber-Q 未下单，无流片；不得作为公开或可引用结果。
> 以下全部为仿真预测。衬底叠层（SiO₂ 厚度）为**假设值**。

## 1) 模型

- 截面与第 7、8 步一致：周期 1.84 µm，NP = 7（平板宽 12.88 µm），平板 400 nm，脊 1 µm × 400 nm，波长 1550 nm，
  TE0；叉指铝 100 nm（n = 1.44 + 16i）在中间三个周期外。LN 取 n_e = 2.138、n_o = 2.211，SiO₂ n = 1.444，Si n = 3.476（无损）。
- 算例（`Step9Trans.java`）：
  - S0：悬空，脊下为空气，无叉指。SF：悬空，带叉指（本设计的有源段截面）。
  - O2 / O1 / O4：脊在 SiO₂（2 / 1 / 4 µm）加 2 µm Si 上，无叉指（普通波导截面）。
- 每个算例求 TE0，导出 Ex、Ey、Hx、Hy 到网格（脊周围 ±3.5 µm，窗外场可忽略），
  `post_step9_trans.py` 做单模模式匹配：连续的 E_t、H_t 分别投影到 H_b*、E_b*，得到
  r = (C − A)/(C + A)，t = 2AC/((A + C)N_b)，T = |t|²·Re N_b/Re N_a，R = |r|²
  （A = ∫(E_a × H_b*)_z，C = ∫(E_b* × H_a)_z，N = ∫(E × H*)_z）。
- 网格收敛：截面网格（LN 25 / 14 nm，其余 110 / 70 nm）和导出间距（10 / 5 nm）都加密一次（`Step9TransF.java`，`FINE=true`）。

- SiO₂ 2 µm 以上衬底漏光可忽略；1 µm 时漏光 0.55 dB/cm（Si 当作无损，所以是漏入衬底的功率）。

## 3) 过渡（悬空 ↔ 普通波导，突变）

| 比较 | T（透射到基模） | 损耗 | R（反射） | E 场重叠 | H 场重叠 | 其余功率 1 − T − R |
|---|---|---|---|---|---|---|
| S0 → O2 | 0.99429 | **0.0249 dB** | 6.5e-6 | 0.99432 | 0.99429 | 0.57% |
| SF → O2 | 0.99429 | 0.0249 dB | 6.5e-6 | 0.99432 | 0.99429 | 0.57% |
| S0 → O1 / O4 | 0.99430 / 0.99429 | 0.0248 / 0.0249 dB | 6.5e-6 | | | 0.57% |
| O2 → S0（反向） | 0.99429 | 0.0249 dB | 6.5e-6 | 0.99432 | 0.99429 | 0.57% |

- 粗细两套网格的 T 与 R 相同到五位有效数字；自比对（S0 → S0 等）T = 1。互易性成立（正反向 T 相同）。
- 带不带叉指、SiO₂ 厚 1–4 µm 对结果没有影响（脊附近的场只看到 LN 和下方的空气或氧化层）。
- 作为交叉检验：R 与 Fresnel 估计 ((Δneff)/(2neff))² = 7.7e-6 一致。
- `post_step9_trans.py` 里的 `eta_ov` 把 E_a 与 H_b 混合，在 a ≠ b 时不对称（0.9994 / 0.9892），不作结果引用；
  E 场重叠与 H 场重叠与 T 互相吻合。

## 4) 结论

- 每个突变过渡的功率损耗约 0.57%（0.025 dB），反射 6.5e-6。一个 1 mm 悬空段两端共两个过渡，约 0.05 dB。
- 反射形成的法布里–珀罗纹波峰峰值约 4R ≈ 3e-5（约 1e-4 dB），可以忽略。
- 悬空段自身传播损耗约 0.0005 dB/cm，1 mm 为 5e-4 dB，所以过渡损耗是悬空段光学损耗的主要部分，但绝对值很小。
- 不需要为光学原因加锥形过渡。调制效率 P·L 与过渡无关。

## 5) 未覆盖 / 风险

- 只是二维截面的突变匹配。释放边缘的真实三维形貌（刻蚀斜面、底切圆角、侧壁粗糙度引起的散射）、
  释放槽与支撑梁附近的横向几何变化都没有算。其余 0.57% 去向（高阶模、辐射）也没有分解。
- SiO₂ 厚度是假设值；若实际 BOX 小于 2 µm，普通波导段会漏光（1 µm 时 0.55 dB/cm）。
- 实测建议：用不同悬空长度的波导做截断法，从长度外推拆出每个过渡的损耗（预测约 0.025 dB，但会叠加粗糙度散射）。
- 光纤端面耦合不在本步范围内。
