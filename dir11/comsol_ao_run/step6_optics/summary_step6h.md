# Step 6h：降功率（铝指加厚、分段馈电、NP=11 超胞）

仿真预测与解析估算，非实测。本稿仅限课题组内部。

文件：
- Step6h.java 是通用源码。Step6hT200.java、Step6hT300.java、Step6hNP11.java 由它生成，只有 CASE 常量不同；
  COMSOL 批处理的安全管理器禁止 Java 读取环境变量，所以每个算例单独编译一个类。
- step6h_T200.log、step6h_T300.log、step6h_NP11.log：每个算例都做了 TE0 光学解、3.25–3.40 GHz 粗扫（1 MHz）、
  对 |tot| 局部极大值（≥15% 全局最大，最多 3 个）在 [f−2, f+5] MHz 内以 0.1 MHz 细扫，以及 40 个本征模
  （u/v/w、fracAl、Pfrac、缺陷区应变能占比）。
- post_step6h.py，step6h_power.log：分布 RC 电极模型（同 6g，按各算例的铝厚和指对数取电阻），给出峰频处功率、
  按频率和孔径优化后的功率，以及 K=1/2/4/8 段并联馈电。
  基准算例 T100（NP=15、铝 100 nm）的数据取自 step6f.log 和 step6gY.log。

功率公式：I_π = π|Y|/(k0|tot|)，P_源 = K·Re(Z_seg(L/K))·|I_π/K|²/2。按无损匹配到 50 Ω 计；
汇流条和馈电网络都按理想导体处理。

200 nm 时只有一个局部极大值超过 15% 门限。

**结论：加厚铝指改变了模式结构，与 100 nm 的结果不能直接比较。**
- 被驱动的峰 fracAl 升到 0.32–0.54（原设计约 0.045），振动大量进入铝指。原来以 v 为主的目标模族移到了
  3.37–3.39 GHz：200 nm 时为 k=25（3.3928 GHz，v 0.88，fracAl 0.19，Pfrac 0.86）；
  300 nm 时为 k=28/30（3.372/3.381 GHz，v 0.81/0.79，fracAl 0.25/0.24，Pfrac 只有 0.019/0.003）。
  它们都没有形成明显的 |tot| 峰。
- **Q 被高估**：模型只在 LN 上加了阻尼（η=5e-4），铝是无损的。铝能量占比越高 Q 越高，
  这正是 Q 升到 3200–4600 的原因。实际中铝的声学损耗会把 Q 和 |tot| 拉低。
- 加厚后电极电阻下降：每毫米 413（100 nm）→ 207（200 nm）→ 138 Ω（300 nm）。
- TE0 损耗下降：0.188 → 0.069 → 0.058 dB/cm。neff 只变 3e-7。原因未查。
- 要公平评估加厚铝指，需要先按新铝厚重调周期（重走 6d-1/6d-2），并给铝加声学阻尼。

## 2) 分段馈电（后处理）

基准算例（100 nm，NP=15）。表中“优化 f”指在峰附近 [f−3, f+6] MHz 内取功率最小的频点；单位 W。

| 峰 | L | K=1 峰频 / 优化 f | K=2 | K=4 | K=8 峰频 / 优化 f |
|---|---|---|---|---|---|
| 主峰 | 0.2 mm | 91.6 / 69.3 | 74.1 / 68.5 | 69.7 / 68.3 | 68.6 / 68.1 |
| 主峰 | 1 mm | 123.2 / 18.9 | 42.3 / 15.0 | 20.9 / 14.0 | 15.5 / 13.7 |
| 低频峰 | 0.2 mm | 3.76 / 3.76 | 2.48 / 2.45 | 2.16 / 2.05 | 2.08 / 1.91 |
| 低频峰 | 1 mm | 8.86 / 8.81 | 2.54 / 2.53 | 0.943 / 0.943 | **0.544 / 0.541** |

- 分段让每段的 |γL/K| 变小，于是电压沿指长更均匀，回流电阻 rL/(2K) 也随之下降。
  L=1 mm、K=8 时，低频峰降到 0.54 W，主峰降到 15.5 W（峰频）或 13.7 W（反谐振侧）。
- L=0.2 mm 时分段帮助不大：这时功率主要由 Re(1/(YL)) 决定（孔径短、声学负载电导大），而不是电极电阻。
- 在 K≤8、L≤5 mm 范围内优化：低频峰最低 0.47 W（K=8，L≈1.8 mm）；主峰最低 3.1 W（K=8，L 取到上限 5 mm，
  频点在反谐振侧 3.342 GHz）。主峰的最优 L 落在扫描上限，说明再长还能降，但会越来越接近理想电极的极限
  （P ∝ 1/L）。

## 3) NP=11、Ndef=3 超胞（铝 100 nm，周期不变）

| 项 | NP=15 | NP=11 |
|---|---|---|
| 超胞宽度 / 指对数 | 40.66 µm / 12 | 29.81 µm / 8 |
| 期望 fracAl（驱动/伙伴，按单胞比例缩放） | 0.0486 / 0.0717 | 0.0442 / 0.0652 |
| TE0 neff / 损耗 | 1.91622316 / 0.188 | 1.91622310 / 0.187 |
| **主峰** f (GHz) | 3.338550 | 3.341800（+3.25 MHz） |
| 主峰 \|tot\| / Q | 8.91e-5 / 2230 | **1.03e-4** / 2221 |
| 主峰本征 u/v/w，fracAl，Pfrac | 0.09/0.89/0.02，0.047，0.970 | 0.08/0.79/0.13，0.045，0.976 |
| 主峰缺陷区应变能占比（几何占比） | 0.233（0.200） | 0.299（0.273） |
| 主峰 Re(Y), Im(Y) (S/m) | 361, 70 | 176, 49 |
| 主峰 I_π (A) | 3.20 | 1.37 |
| 主峰 P_源，K=1，优化 f、L | 16.9 W | 6.1 W |
| **低频峰** f (GHz) | 3.318700 | **3.250200（−68.5 MHz）** |
| 低频峰 \|tot\| / Q | 8.21e-5 / 2159 | 6.32e-5 / 2168 |
| 低频峰本征 u 占比，Pfrac | 0.96，0.001 | 0.95，0.003 |
| 低频峰 P_源，K=1，优化 | 3.74 W | 2.67 W |
| 第三个峰 | — | 3.3476 GHz，w 为主（伙伴模，fracAl 0.064） |

- **主峰稳定**：频率只变 0.1%，fracAl 和 Pfrac 不变。|tot| 增大 16%，因为缺陷区在超胞中的占比变大了。
  Y 约减半（8 对指、超胞更窄），所以 I_π 和功率都明显下降。
  也就是说，每根脊配更少的指对可以降功率，但器件宽度和声学驱动能力也随之改变。
- **低频峰随超胞长度大幅移动（−68.5 MHz，−2.1%）**，而且 Pfrac≈0（在叉指周期的谐波上几乎没有分量）。
  它的波矢由超胞周期决定，是超胞折叠出来的模式。**在真实的有限长器件里，它不一定出现在这个频率，甚至不一定存在。**
  6f/6g 中“低频峰功率效率高”的结论，在做非周期（有限长 + 吸收边界）验证之前不能作为器件结论。
- NP=11 第三个峰的分析区间与主峰重叠，它的“优化”功率实际取在主峰的反谐振侧，不单独解读。

## 4) 总结与下一步建议

- 目前唯一在超胞长度变化下稳定、且身份明确的工作模式是**主峰（v 为主）**。
  在 100 nm 铝、理想馈电网络下，它到达 Vπ 的最低信号源功率为：
  - NP=15：K=8 分段时 3.1 W（L=5 mm）；L=1 mm、K=8 时 13.7 W。
  - NP=11：K=8 分段时 0.92 W（L=5 mm）；L=1 mm、K=8 时 2.9 W。
- 低频峰的亚瓦结果（0.33–0.54 W）依赖超胞周期，需要先用有限长模型确认这个模式真实存在。
- 加厚铝指的结果（0.16–0.43 W）是在模式结构已经改变、铝无阻尼、周期没有重调的条件下得到的，只能说明方向。
- 建议的下一步：
  1. 有限长（非周期）叉指加吸收边界，确认主峰和低频峰在真实器件中的存在、频率和 Y。
  2. 每根脊对应的指对数扫描（NP=7、9、11、15），主峰的 I_π 和 Q 怎么变。
  3. 厚铝方案：给铝加阻尼，重调周期后再评估。
- .mph 不入库。
