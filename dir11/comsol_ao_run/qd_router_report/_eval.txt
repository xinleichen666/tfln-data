1.2 "73% 可见度"到底是什么（最容易误读的一处）
它测的是 两个独立 QD 各发一个光子、在 MMI 上干涉的玻色聚束（HOM/HBT）。
HOM 干涉可见度 ≠ 纠缠。 两个完全独立的、不可区分的单光子也能给出完美的 HOM dip——这证明的是"光
子波包不可区分"，而纠缠需要的是同一源内两个模式之间的量子关联（双激子级联的 XX/X 双线偏振符合），必
须做层析或 CHSH 才能宣称。
这既是平台最大的空白，也是本方案的第一个入口。

2. 物理诊断：唯一硬瓶颈是 FSS
2.1 FSS 如何杀死偏振纠缠（严格推导）
双激子级联：|XX⟩ → |X⟩ + 光子_A → |0⟩ + 光子_B 。两条路径（H/V）的中间态因精细结构分裂 FSS 而能量不

2.2 平台"能不能"调零 FSS：四个约束
好消息：机制成立。用各向异性压电应变调零 FSS 是成熟技术（Trotta et al., PRL 109, 147401 (2012)；Seidl
APL 88, 203113 (2006)；Gerardot APL 90, 041101 (2007)）。而且张加祥本人 2015 年就做过这件事
（Zhang et al., Nat. Commun. 6, 10067 (2015)，压电应变调零 FSS，f⁺ = 0.83(5)，成品率 10⁻²→30%）。
当前最好水平：Huber et al., PRL 121, 033902 (2018)，无后选择 F = 0.978(5)、C = 0.97(1)。
但把它平台化有四个硬约束：
约束 1：FSS 权限是边缘的。 用 7.7 meV 反推总应变 ε ≈ 10⁻³；按形变势比估算
ΔFSS_max ≈ (dFSS/dε)/(dE/dε) × 7.7 meV ≈ 10–50 μeV（中心 ~20 μeV）
对典型的 20 μeV FSS 是"刚好/边缘"。关键未知量是各向异性占比 f_a：若 f_a = 0.1，只剩 2–5 μeV，方案不
成立。
约束 2（最硬）：1 个旋钮不够，需要 2 个。
ΔE / ΔFSS ≈ 150–770
即：把 20 μeV 的 FSS 归零，会把发光能量拖走 3–15 meV；而"20 通道同频"的预算只有 0.76 meV。
单一电压、固定应变张量形状的几何，无法同时做到"零 FSS"和"同频"。
约束 3：FSS 是二维矢量。 本征轴沿 [110]/[1−10]，方向随机。固定方向的应变只能修一半的点。需要双轴/双
极执行器，或逐器件设计（见方案 A）。
约束 4：没有 FSS(V) 数据，且铁电畴翻转存在滞后/蠕变/低温重复性问题。

4. 方案 B：偏振分集 + 电光锁相网络——真正属于 TFLN 的那一步
4.1 问题陈述
LN 片上双折射 Δn ≈ 0.07，0.48 mm 就累积 73π 偏振相位。任何偏振纠缠/偏振编码在片上传输都会失相。这
是所有"把偏振量子光学搬到 LN 上"的人都必须面对、但很少有人正面处理的问题。
4.2 方案
偏振分集架构：
1. 用偏振分束器（或 grating coupler + 偏振旋转器）把 TE / TM 分成两条独立波导
2. 两条路径各自经过独立的 电光相位调制器
3. 在输出端用另一个偏振合束器重新合成
4. 用电光反馈把两条路径的相对相位锁定到目标值
关键论点：TFLN 的强电光效应使"主动锁相"成为可能，而且是这套平台独有的能力——其他材料平台要么没有
可用的 EO 相位调制器，要么带宽不够。
4.3 实验设计
先用相干激光标定双折射相位稳定性（测相位漂移谱：mHz–Hz 段）
加入闭环：误差信号 → EO 相位调制器 → 相位抖动压制
转入单光子/纠缠光子，记录：
- 偏振纯度 vs 闭环开关
- 累积 73π 相位后的偏振保真度
- 不同波导长度（0.48 mm → 数 mm）下的保真度衰减曲线
4.4 新颖性与定位
首次在 TFLN 上演示偏振纠缠的片上传输与主动稳相

4.5 必须正面回答的审稿人问题
"既然是慢漂移，为什么要用 GHz 电光？用温控/机械不行吗？"
回答（需要实测支撑）：
1. 先测相位噪声谱，用数据说话——若主要噪声在 Hz 以下，慢环即可，那就诚实地设计慢环；若存在 kHz 以
上的分量，EO 是唯一选择
2. EO 的优势不在"更快"，而在无机械部件、低功耗（μW–mW 级）、可与阵列共集成、不引入热串扰
3. 长波导 + 多器件并行时，每个通道都需要独立稳相——只有集成 EO 调制器能提供阵列化能力，这是温控做
不到的

⚠️ 重要的物理边界（必须写明）：HOM/TPI 的零延迟可见度对慢相位漂移是不敏感的——因为零延迟意

稳相不能用"提升 HOM 可见度"来当卖点。它的真实价值在偏振编码长路径传输（那里相位差会真实累积）
和长积分下的频率锁定。

9. 备选路线：带电激子自旋–光子纠缠（若 FSS 路线受阻）
动机：Kramers 简并天然没有 FSS，从原理上绕开本方案识别的最大障碍。
机制：带电激子 |↑↓,↑⟩，Voigt 构型下自旋态与圆偏振光子一一对应，天然产生自旋–光子纠缠
已有先例：De Greve et al., Nature 491, 421 (2012)——910 nm QD 自旋–光子纠缠，并做到 910→1550
的 QFC。所以这条路线波长与转换都有现成路径
与 TFLN 的契合点：强 EO 效应可以做快速自旋操控/相位锁定，这是 LN 平台真正擅长的事
需要新解决：电荷噪声/核自旋超精细导致的自旋退相干（T₂*）、偏振路由（回到方案 B）
建议：作为并行备选评估，不与 A/B 抢资源；若 A 的判决实验失败，立即切换。
10. 本方案的风险与不确定项（如实列出）
1. FSS 权限边缘（最大风险）：ΔFSS_max ≈ 10–50 μeV 是估算，依赖未知的各向异性占比 f_a。f_a = 0.1 时
方案 A 不成立。 这就是为什么阶段 1 是判决实验。
2. 临界角解耦未验证：θ≈160° "带隙不敏感"是原文明示的，但"是否仍注入各向异性应变"完全没有数据。这是
方案 A 的核心假设。
3. 腔内无法同时增强双线：结合能/线宽 = 28–56，单模腔必然破坏级联平衡。要么双模/宽带腔（工程难度
大），要么放弃腔（β 从 78% 降到 83% 波导值，可接受）。
4. 偏振在 LN 上的固有困难：双折射 73π/0.48mm，方案 B 是必须做而非可选做的。
5. 波长拖累：910 nm 的 1.68 dB/km 意味着片上/机架内演示（mm–cm）是诚实定位；长距必须靠 QFC 或
换材料。
6. 竞争窗口：Beccaceci 2025-12 已占"确定性纠缠交换"，且 npj QI、Nat. Mater. 之后同组/邻组跟进会很
快。
