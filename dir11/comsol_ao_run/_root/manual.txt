2　光波导模式：自己的 ng
新模型，2D，Wave Optics → Electromagnetic Waves, Frequency Domain → Mode Analysis。
论文没有波导宽度和膜厚。有组里的截面就照画。没有的话，先用一个能算通的脊波导把流程走通：铌酸锂厚度 600
nm，刻蚀 300 nm，顶宽 1.2 µm，下面二氧化硅 2 µm，上面空气或 1 µm 二氧化硅。这组尺寸不是论文给定值，记
录表里必须写「教学截面」或「PDK」。
材料搜索 Lithium Niobate，用单晶，不要用各向同性近似。新建 Rotated System：晶体 z（光轴）躺在晶片平面
内，晶体 x 指向晶片法线。这是 X 切。转完以后检查：面内一个方向的折射率应接近非常光，法线方向接近寻常
光。轴反了就改旋转，不要改模式结果去凑 2.3。
计算域左右和衬底底边用散射边界或完美匹配层。脊内网格最大单元约 80 nm。
Mode Analysis：频率 193.4[THz]，搜索的有效折射率中心 2，模式数 20。取能量集中在脊里、neff 最高的那个导
模，记下 neff。
同样的网格再算 193.1[THz] 和 193.7[THz]。
ng = neff − f · (neff2 − neff1) / (f2 − f1)
f 取 193.4 THz，neff 取这一次的结果，下标 1、2 是 193.1 与 193.7 THz。
对上了：ng 落在大约 2.1–2.4。论文写 2.3 是假定。用你的 ng，不要改输入去凑 2.3。以后式 (2) 里的环长频率因
子全部用这个 ng。
3　双波导：把裂距调到 3.33 GHz
仍用二维截面，画两根与第二部分相同的脊，间隙 g，共用一个计算域。Mode Analysis 会给出偶模和奇模两个 neff。
裂距来自耦合段上多走的相位，再除以整圈时间：
Δf = (Δneff · Lc / λ) · c / (ng · Lring)
Lring = 0.667[mm]，λ = c/193.4[THz]，Δneff = neff偶 − neff奇
c / (ng · Lring) 是这颗环的自由光谱区。ng = 2.3 时大约 196 GHz。
这个 Δf 就是论文里的超模裂距 2µ/(2π)。目标是 3.33 GHz。
先固定耦合长度 Lc = 40[µm]，扫 g = 0.3、0.4、0.5、0.6、0.8 µm。
每个 g 记录 Δneff 和 Δf。
论文的可调耦合器要求最大裂距大约 3.33×√2 = 4.71 GHz，加热到一半时才是 3.33 GHz。选一组 (g, Lc)，使最大 Δf
接近 4.71 GHz。冷态工作点由第六部分的加热相位决定，不在这一步用死间隙凑 3.33。
间隙误差以后按论文的衰减长度换算，不需要再跑模式：5 nm 对应大约 3.33 GHz × (5/150) = 111 MHz。论文写的
是约 114 MHz，同一量级。

5　光弹：每伏能把共振推多远
电极上加的是第四部分那个 1 V 的解。应变改变折射率，模式的 neff 跟着变，再用论文式 (2) 换成整颗环的频率移动。
在光学模型里把第四部分的应变导进来，或把应变分量做成参数。优先用材料库里铌酸锂的光弹系数把应变写成
Δε。库里没有系数时，先只做「应变已换成 Δn」的流程，系数表单独注明出处，不要默默使用一组记不清符号的
数。
对加应变和不加应变各算一次第二部分的导模，得到 Δneff。
100 µm 作用长度上的相位，以及整圈造成的频率移动：
Δφ = 2*pi/λ · Δneff · La ， La = 100[µm]
δf = Δφ · c / (2*pi · ng · Lring)
这就是式 (2)。δf 的单位是 Hz，除以电极电压 1 V，就是你的每伏频移。
ξ = （你的 δf，单位 GHz/V） / 21.3
对上了：ξ 在 0.3–2 之间都可以往下做。论文把 21.3 GHz/V 定为 ξ = 1，那是邵 2019 直波导的外推，不是你这个
截面的测量。ξ 小于 0.5 时，第五部分的功率表会升到几百微瓦以上，仍可以记录，但要在第七部分显式写出来。
若 δf 是在电极 1 V 下直接算的，它已经包含模型里的机电耦合。后面的源功率用 P = V²/(2×50 Ω)，不要再乘叉指
效率，否则算重了。叉指效率只在你故意把结果归一化到邵的 21.3 GHz/V 时才另乘。
