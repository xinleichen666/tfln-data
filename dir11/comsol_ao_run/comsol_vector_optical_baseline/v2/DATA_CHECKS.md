## B. 数据诊断

| 文件 | 节点 | neff | normE 与 \|E\| 相对差（全点 / 去重后） | 重复点 | 重复点场值差 |
|---|---:|---|---|---:|---|
| f_nomA6_m40 | 32 055 | 1.7819 | 0.16 % / 0.14 % | 266 | 38 V/m |
| f_metA6_m40 | 32 222 | 2.1548−0.01587i | 2.55 % / 1.24 % | 324 | 213 V/m |
| f_k3_m38 | 32 222 | 1.7194−0.13365i | 2.55 % / 0.91 % | 324 | 88 V/m |

**解释：**重复坐标是材料界面同点的两侧取值（COMSOL 在界面处导出不连续量），
其场值差异达数十至数百 V/m。这也解释了 `normE` 与复分量重建的偏差——全点比较
把两侧值混在一起，去重后偏差降到 1 % 量级。

**结论：**数据可用，但必须显式处理界面重复点；不能把导出当成普通单值点云。

### 修正后的判断

1. **此前"重叠 1.0084 → 同一分支"不成立。**改用有界共轭指标后，κ=3 的 m38 为 **0.8871**——
   相似但不是同一，不能据此宣布分支确认。
2. **κ=15.6 时最佳只有 0.5241**，且多个候选模与参考模几乎正交（S≈0）。
   这比旧指标（0.736）弱得多，**更不支持"找到了目标模"**。
3. 网格敏感性 0.0005–0.0038，说明 S 本身是稳定的；数值不是抽样噪声。
4. κ=3 与 κ=15.6 之间仍**没有**建立连续链条。
