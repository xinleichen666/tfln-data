# COMSOL 全矢量光模基准：状态（2026-10-21，第 4 版）

## 本轮新增：符号约定已标定

用一个**物理上无歧义**的损耗源做标定：把 LN 折射率设为 `2.211 − 0.001i`。

| 设置 | Im(neff) | dampz |
|---|---:|---:|
| 芯层 n = 2.211 − 0.001i | **−1.010×10⁻³** | **+4.095×10³** |

理论预期 Γ·κ ≈ 0.78 × 0.001 = 7.8×10⁻⁴，与 1.01×10⁻³ 同量级。
**结论：本模型里吸收对应 Im(neff) < 0、dampz > 0。**

因此铝必须写成 `1.44 − 15.6i`（ε = −241 − 44.9i，Im(ε) < 0）。
此前用 `+15.6i` 得到 Im(neff) > 0、dampz < 0，那是**增益**，相关结论作废。

## 已确认结果

### 无金属：脊模已收敛

| 网格 hmax | 三角单元 | neff | 脊内占比* | LN 内占比* |
|---|---:|---:|---:|---:|
| 25 nm | 62 896 | 1.787990 | 61.0 % | 78.3 % |
| 15 nm | 174 462 | 1.787961 | 60.9 % | 78.1 % |

两次差 2.9×10⁻⁵（0.0016 %），重心在 x = 1.289 μm（脊中心）。
与标量 EIM 的 1.839 差 2.7 %，属标量近似偏差。

### 含金属（符号已修正）

| mode | Re(neff) | Im(neff) | dampz | 脊内占比* | LN 内占比* | 损耗 |
|---|---:|---:|---:|---:|---:|---:|
| 37 | 1.8092 | −1.66×10⁻² | +6.7×10⁴ | 8.5 % | 67.8 % | 5.8×10³ dB/cm |
| 38 | 1.8383 | −1.49×10⁻² | +6.0×10⁴ | 5.7 % | 68.2 % | 5.2×10³ dB/cm |
| 40 | 2.1582 | −1.63×10⁻² | +6.6×10⁴ | 68.1 % | 87.3 % | 5.7×10³ dB/cm |

\*近似 |E|² 积分占比，不是功率约束因子。
损耗换算 α = 2k₀|Im(neff)|。

**注意**：加金属后，原本 61 % 在脊内的介质模，脊内占比掉到 5.7–8.5 %
（能量被推向平板区并大量被金属吸收），说明扰动不是小量。

## 结构含义（有证据支持）

脊宽 0.645 μm 恰好填满两指条之间的无金属间隙，**脊侧壁与铝直接相接**。
在这个布局下损耗约 5×10³ dB/cm：6 μm 上约 3 dB，100 μm 上完全不可用。

**修法：把脊收窄留出与金属的间隙，或加低折射率包覆。** 这需要改结构后重算，
不是单纯调参数。

## 复现

```powershell
cd D:\comsol_ao_run\comsol_vector_optical_baseline
python run_case.py 0 25 1.6 nom25 1.80 0 0 -      # 无金属
```
