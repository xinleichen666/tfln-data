# 方向 15 报告 v1：激光直写三维结构与 TFLN 量子芯片的混合集成

（工作包，2026-10-07；迭代细节见 iter_log.md）

## 1. 一句话结论
单纯做“直写耦合器降损耗”比不过现有最好的单片耦合器（0.29 dB/端面），也没有新意，已放弃。真正值得写的是：**在 TFLN 芯片端面直接直写多平面光转换器（MPLC），把片上几根波导的光变成 LG 模高维量子门，再用片上电光移相器微调**。仿真显示 d=3 门名义保真度 0.998，在真实工艺误差下仍有 0.96–0.99，最关键的工艺指标是层与层之间的横向对准要控制在 0.1–0.2 µm 以内。

## 2. 方法与求解器验证
- 模式：自写半矢量有限差分求解器（modes.py），平板波导解析解验证，neff 误差约 1e-4。网格 40 nm，窗口 12×10 µm。小尖端（neff 接近包层）的模场会被窗口截断，这部分结果只作趋势参考。
- MPLC：角谱传播 + 薄相位板 + 波前匹配优化（mplc.py），网格 160×160、像素 1 µm，相位按 0.1 µm 高度台阶量化（n=1.53，空气中）。
- 假设（都要实验确认）：树脂 n=1.53 且无色散、无吸收；薄元件、标量近似；**没有计入菲涅尔反射**；误差都按高斯随机处理。

## 3. 第 1 轮：耦合器（fig/iter1_tip_coupling.png）
| 方案 | 本文仿真 | 文献最好（同指标） |
|---|---|---|
| 单片倒锥直接对 SMF-28 | 0.5 dB（300 nm 膜、0.15 µm 尖端，氧化硅包层） | 0.29 dB 实测，>180 nm，PDL<0.17 dB（[APL Photon. 9,116111 (2024)](https://pubs.aip.org/aip/app/article/9/11/116111/3322374)） |
| 理想直写透镜（模场放大） | 0.07–0.3 dB + 菲涅尔约 0.2–0.4 dB | FaML 1.4 dB、±6 µm（硅光，[Light:AM 2023](https://www.light-am.com/article/doi/10.37188/lam.2023.003)） |
| 直写离面耦合器 | — | 1.3 dB @1550、2.9 dB @775（C5，[arXiv 2511.17327](https://arxiv.org/abs/2511.17327)） |
| 聚合物锥 / PWB | 0.7–0.9 dB（估算） | 1.78 dB（[Vanguard/KIT](https://publikationen.bibliothek.kit.edu/1000178837/156938023)）；SU-8 双层锥 1.4 dB（B3，[arXiv 2508.08599](https://arxiv.org/abs/2508.08599)） |

设计规则：树脂（1.53）包住小尖端时，衬底 SiO2 折射率更低，宽度 ≤0.3 µm 的尖端模式不再被束缚。

## 4. 第 2 轮：对量子性能的影响（fig/iter2_squeezing.png）
用 B3 参数验证：算出可测 1.33 dB，论文实测 1.4 dB。片上 10 dB 压缩时，耦合 1.4 dB → 0 dB，可测压缩只从 1.9 dB 升到 3.0 dB，因为其余 2.6 dB 损耗才是大头。这部分只作为动机。

## 5. 第 3–4 轮：端面直写 MPLC 高维门（fig/iter3_*.png）
结构：3 根波导（间距 10 µm），4 层相位板，层间 40 µm，像素 1 µm，总长约 200 µm，输出 LG ℓ=-1,0,+1（光腰 8 µm）。

| 情况 | 保真度（固定） | 保真度（片上相位微调） | 插损 (dB) |
|---|---|---|---|
| 名义，4 层 | 0.998 | 0.998 | 0.45 |
| 名义，5 层 | 0.999 | 0.999 | 0.30 |
| 层错位 0.1 / 0.25 / 0.5 µm | 0.996 / 0.974 / 0.90 | 0.998 / 0.990 / 0.95 | 0.7 / 1.8 / 3.9 |
| 输入平移 1 µm | 0.998 | 0.998 | 1.1 |
| 高度误差 50 / 100 nm（相关 3 µm） | 0.993 / 0.971 | 0.997 / 0.990 | 0.6 / 1.1 |
| 收缩 5% / 层距误差 2 µm | 0.996 / 0.980 | 0.998 / 0.992 | 0.7 / 1.7 |
| 波长 1.53 / 1.57 µm | 0.992 / 0.989 | 0.998 / 0.994 | 1.0 |
| **综合真实误差（n=20）** | **0.964** | **0.987** | **2.2** |
| 综合误差 + 自由空间对准 2 µm | 0.938 | 0.970 | 6.0 |
| d=5，7 层，综合误差 | 0.956 | 0.983 | 2.0 |

对比：U2 直写 MPLC 自由空间输入，**实验**过程保真度 90.1%（[Sci. Adv. 2025](https://doi.org/10.1126/sciadv.adv5718)）。我们是仿真，不能直接说更好；能说的是“端面直写省掉了输入对准这一项误差，且 TFLN 移相器能补偿剩下的相位误差”。

新颖性检查：LNOI 超表面加电极做 GHz 切换 OAM（[arXiv 2311.08867](https://arxiv.org/abs/2311.08867)）只做单个波前，不是多模幺正门；光子灯笼打印在多芯光纤端面上（6 模，插损 2.6 dB）；自由空间 MPLC 耦合到硅多模波导用的是 SLM（[arXiv 2512.02658](https://arxiv.org/abs/2512.02658)）；直写 MPLC 的综述（[arXiv 2602.07222](https://arxiv.org/html/2602.07222)）也没有提到芯片端面集成。没有找到同样的构型，但检索不可能穷尽，投稿前请文献包再查一次。

负面结果：在优化中加入平滑约束来提高容差，综合误差下反而更差（0.953 对 0.964），不采用。

## 6. 局限（必须在论文里写明）
1. 菲涅尔反射没有算：4 块板 8 个面约 1.5 dB，要用增透结构、折射率匹配封装，或改成整块树脂里的折射率调制。
2. 薄元件、标量近似：像素 1 µm、台阶最高 3 µm，需要用 FDTD 抽查一层（我们没有商业软件，可以请组里用 COMSOL/Lumerical）。
3. 树脂吸收、色散、耐光强和低温性能没有数据（E3 方向），泵浦光不能经过 MPLC。
4. 蒙特卡洛每项 10–20 次，正式投稿前要加到 ≥100 次。

## 7. 论文提纲
- **题目**：Laser-written multi-plane light converters on thin-film lithium niobate chip facets for high-dimensional spatial-mode quantum gates（薄膜铌酸锂芯片端面直写多平面光转换器实现高维空间模式量子门）
- **摘要要点**：端面直写 4–7 层 MPLC，把片上波导路径模式直接映射为 LG 模；d=3/5 Fourier 门名义保真度 >0.99；给出 6 类工艺误差的容差和 TFLN 电光相位补偿；指出层间横向对准是首要工艺指标；和自由空间对准方案对比。
- **图**：1 构型示意 + 相位板；2 输出场和转移矩阵；3 六类误差的容差曲线；4 综合误差统计 + 相位补偿前后；5 d=3/5、层数与插损/保真度的关系；6 对量子源的系统效率（含压缩/预报）。
- **主张**：(1) 新构型；(2) 定量工艺窗口；(3) 片上相位补偿把保真度从 0.96 提到 0.99。不主张新算法（波前匹配是 Fontaine 等的方法）。
- **期刊**：仿真加经典验证 → Optics Express / Optics Letters；加上单光子过程层析 → APL Photonics / Photonics Research。

## 8. 实验方案（直写 + 台面）
1. **玻璃上先打样（1–2 个月）**：用组里的双光子直写，在熔石英或 V 槽光纤阵列（127 µm 间距；用 3 根 SMF 加直写聚合物锥，把间距缩到 10 µm）端面写 4 层 MPLC，按本设计重新优化。先写单层标定“高度–相位”和收缩率，再写 4 层。
2. **经典测试**：1550 nm 可调激光依次从每路输入，用 InGaAs 相机 + 4f 成像看输出模式；用 SLM 或柱透镜做模式分解，测转移矩阵 |T|² 和插损；扫 1520–1600 nm 测带宽；用 SEM/共聚焦测层间错位，和图 3 的容差曲线比较。
3. **相位补偿**：在光纤输入端加压电光纤移相器或商用 LN 相位调制器，模拟片上 TFLN 移相器，验证保真度从约 0.96 提到 0.99。
4. **量子验证**：用商用 PPLN/PPKTP SPDC 光源（1550 nm），一个光子预报，另一个进 MPLC，做 3 维过程层析（与 U2 同样的方法，可直接对比 90.1%）；然后做双光子 HOM 型多端口干涉。
5. **上 TFLN 芯片**：拿到商用或 MPW 芯片（HyperLight 渠道价格和周期未核实）后，在端面抛光面上直接写；注意树脂折射率规则（第 3 节）。
关键风险：显影收缩造成的层间变形；多层自由悬空结构的机械稳定性（需要支撑柱或整体封装）；菲涅尔损耗。
